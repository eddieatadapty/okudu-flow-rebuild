# Okudu Growth Audit

**Live → https://eddieatadapty.github.io/okudu-flow-rebuild/**

Five ideas to turn more Okudu users into subscribers, each built into a clickable version of Okudu's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Name their story on the plan screen | +10–20% CR to purchase |
| 02 | Write chapter 1 before the sign-in | +5–10% CR to purchase |
| 03 | Price credits in chapters, next to what’s free | +10–20% CR to purchase |
| 04 | Skip the questions the first answer already covered | +5–15% CR to purchase |
| 05 | Catch the people who close Premium | +10–15% ARPU |

Every price, rating and feature comes from Okudu's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Okudu. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
